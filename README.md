# 水瀬市ドライブ（MINASE DRIVE）— 開発版 v0.9.3（仮版）

架空の地方都市「水瀬市」を軽自動車（ミライース）で走るブラウザ用3Dドライブシミュレーター。WebGL2、外部ライブラリなし、ビルド不要の静的ファイルのみ（GitHub Pages でそのまま動きます）。

- **修正102 季節ごとのドライブBGM**（`src/ld_music.js`）：春・夏・秋・冬 各10曲（すべて Web Audio のコード生成。曲名つき）。春＝ギター／ピアノ中心の軽快な曲、夏＝トロピカルなパーカッション・ブラス風・スティールパン風、秋＝ジャズ／ボサノバ寄り、冬＝ベル・ストリングス・コーラス風のクリスマスソング風（実在曲の旋律の模倣なし）。シャッフル袋で再生（同じ曲が連続しない・一巡するまで重ならない）。HUD右上の音楽のまとまり：曲名チップ（押すと次の曲）・⏭（次の曲）・「BGM ON/OFF」。キーボードは M＝ON/OFF、B（または .）＝次の曲。ON/OFF は保存。市街地のBGM・切替操作は従来どおり

## 1. 起動方法

ES Modules を使うので、ファイルを直接開くのではなくローカルサーバー経由で開きます。

```
cd minase-drive
python3 -m http.server 8000      # または npx serve .
# ブラウザで http://localhost:8000/ を開く
```

ビルドは不要です。静的ファイルだけで動くので、そのままWebサーバーに置けば公開できます。
WebGL 2.0 対応ブラウザが必要です（Chrome / Edge / Safari 15以降 / Android Chrome）。WebGPUは使いません。

## 2. 技術選定

| 観点 | Three.js | Babylon.js | PlayCanvas | 自前の軽量WebGL2（採用） |
|---|---|---|---|---|
| 3D描画性能 | 高い | 高い | 高い | 高い（用途を絞れる） |
| 大規模マップ | 自前実装が必要 | 一部機能あり | エディタ前提 | チャンク管理を自前実装 |
| NPC大量描画 | InstancedMesh | Thin Instances | あり | 共有メッシュ＋描画単位を最小化 |
| 車両物理 | 外部ライブラリ | Havok連携 | ammo.js | 自前の簡易タイヤモデル |
| 交通AI | 自前 | 自前 | 自前 | 自前（どれも同じ） |
| 3Dモデル管理 | GLTFLoader | 強力 | 強力 | 手続き生成（GLB読込は未実装） |
| メモリ | 中 | 大きめ | 中 | 小さい |
| Claudeによる生成・保守 | とても良い | 良い | エディタ依存で不向き | 良い（コードが短く全体を把握しやすい） |
| 将来の拡張 | 豊富 | 豊富 | 豊富 | 必要な分を足していく |
| 開発コスト | 低 | 中 | 中 | 中 |

**長期的な推奨は Three.js（＋TypeScript＋Vite）** です。GLBモデルの読み込み、影、ポストエフェクトなどが必要になる段階で移行する価値があります。
今回は、開発環境からCDNやnpmに接続できず実機で動作確認できるライブラリを使えなかったこと、PS2風の表現なら必要な機能が少ないことから、
**依存ゼロの自前WebGL2レンダラー**で実装しました。描画部分は `renderer.js` に閉じているので、後からThree.jsに置き換えられます。

## 5. 仮素材・制限事項（正直な現状）

- **車両はすべて手続き生成のローポリ仮モデル**です。ミライースは v0.2 で形を作り直しましたが、実車の正確な再現ではありません。NPCの他の49車種は v0.1 と同じパラメトリックモデルです。GLB/glTFの読み込みは未実装です。ロゴ・エンブレムは入れていません。
- 車種名は「参考車種」としてデータ上にのみ持っています。公開作品で実車名を前面に出す場合は、各社の商標の扱いを確認してください。
- 看板・店名はすべて架空です。BGMと効果音はWebAudioの合成音です。BGMの曲はこのゲーム用に手続き生成したオリジナルで、既存曲は使っていません。
- 立体交差は「またぐ」だけで、バイパスと国道をつなぐランプ（インターチェンジ）はありません。
- 駅前ロータリーを周回するのはタクシー2台とワゴン1台の専用車両です。一般のNPCはロータリーに入りません。
- 地形の起伏は山間部だけで、市街地・郊外・田園は平らです。建物の影はなく、車の下の簡易な影だけです。
- 郊外の外周道路には歩道がありません。歩行者は歩道のない道では路肩を歩きます。
- 動作確認はヘッドレスChrome（ソフトウェアWebGL）で行いました。**実機スマートフォンでのフレームレートは未計測**です。中心部と郊外が同時に見える場所では描画が約23万ポリゴンになります。

## 6. 検証結果（ヘッドレスChrome、v0.2）

- 交通シミュレーション（中心部・国道・郊外・山・田園で計約45分ぶん）：赤信号での交差点進入 0件、プレイヤー周辺140m以内での車両の重なり 0回（最終版）、立ち往生の最長 約9秒（自動回復の発動まで）
- 検証中に見つけて直した不具合：駐車場の出入口で入庫車と出庫車が譲り合って動けなくなる問題、車線変更時の追突、右折待ちの停止位置
- マップ全域を3周テレポートしても、メッシュ数とメモリは増え続けない（読み込み中のチャンクは256個中14〜32個）
- 物理：0→100km/h 約12.5秒、100km/hからの制動 約41m
